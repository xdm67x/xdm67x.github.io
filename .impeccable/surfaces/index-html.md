# Surface brief — index.html (portfolio, single page)

## Scope and visitor mode

Experience. Portfolio surface for Mehmet Ozkan; the artifact leads and the interface recedes into game chrome.

## Audience, job, action, proof, constraints

Recruiters and engineer-collaborators; they judge range and depth in under two minutes, then act (GitHub, LinkedIn, email). Proof: Doctolib product work, ICube VR/AR research + publication, 9 real repos, real skills from the CV. Constraints: static GitHub Pages deploy, Bun + Vite + Three.js (user-confirmed), works without WebGL / reduced-motion, factual content only.

## Direction contract

THESIS: the portfolio is a playable journey — one continuous WebGL shader world the visitor travels through, level by level; refuses the card-grid portfolio default and decorated-static-section thinking.

OWN-WORLD: deep night-indigo world ground, adventure gold as the one UI accent with crystal cyan for tech lines; RPG dialogue-box panels (dark, gold hairline border, corner ticks); pixel-font HUD chrome (Press Start 2P) over a Chakra Petch body; biome-shifting fBm sky with parallax ridgelines, stars and drifting motes.

STORY: visitor presses START at the title screen, walks the quest log (experience), collects side quests (projects), reads the inventory (skills), answers CONTINUE? (contact) — and exits through a real link.

FIRST VIEWPORT: arcade title screen. Boot overlay types out then fades; centered pixel logotype "MEHMET OZKAN" over the animated night sky, tagline and bio beneath, a blinking "PRESS START" control as the primary action, animated biome 0 (night sky + moon + ridgelines).

FORM: brief-pinned direction (gaming adventure + WebGL shaders, stated by the user); no concept roll. Code-led build (no image generation in harness). Signature interaction: scroll = world traversal — the shader biome and HUD (level, HP bar, secrets counter) evolve continuously with the journey.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
